# 3-Column Preview Card Component

## Project Overview

This project is a responsive three-column card component that showcases three vehicle categories: **Sedans**, **SUVs**, and **Luxury** cars. Each card includes an icon, a title, descriptive text, and a **Learn More** button. The layout is built with Flexbox, allowing the cards to display in a horizontal row on larger screens and stack vertically on smaller devices. Smooth entry animations and interactive hover effects enhance the overall user experience.

## Features

- Responsive Flexbox layout
- Three themed vehicle cards
- Clean and maintainable CSS structure

## What I Learned

### Responsive Layouts
- Used `flex-wrap` and `min-width` to create a flexible layout that adapts to different screen sizes without relying on media queries.

### Positioning
- Gained a better understanding of how `position: absolute` elements depend on a parent container with `position: relative` for proper alignment.

### Design Consistency
- Matched button colors with their respective card themes.

### Code Organization
- Structured CSS with clear, descriptive class names.
